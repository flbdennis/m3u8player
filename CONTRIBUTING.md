# Contributing

Contributions are welcome when they improve public or authorized browser playback testing.

## Good contributions

Useful additions include:

- Clearer M3U8/HLS browser playback explanations.
- CORS, MIME type, codec, HTTPS, signed URL, and segment debugging notes.
- Public test stream checklists.
- Embed examples for pages you control.
- Notes about open source player libraries such as hls.js, video.js, dash.js, and Shaka Player.
- Corrections that make guides more accurate, practical, or easier to read.

## Not accepted

Do not submit content about:

- Downloading copyrighted streams.
- Stream ripping.
- DRM bypassing.
- Login, cookie, token, or paywall workarounds.
- Extracting private video URLs.
- Platform-specific download bypasses.
- “Download any video” workflows.

## Writing style

Keep guides practical:

- Explain the symptom.
- Explain the likely browser or source-server cause.
- Show what to check first.
- Keep examples generic.
- Link to the MetisTools player only when it helps the user test a public or authorized stream.

## Pull request checklist

Before opening a pull request:

- Confirm that links are real and useful.
- Avoid unverifiable claims or fake success rates.
- Avoid private media URLs in examples.
- Avoid screenshots that expose tokens, signatures, cookies, or user-specific links.
- Use plain English and short sections.
