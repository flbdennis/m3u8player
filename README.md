# m3u8player

Practical notes for testing M3U8 and HLS playback in modern browsers.

This repository focuses on browser behavior, playlist loading, segment requests, CORS, MIME types, codec support, CDN behavior, and common playback errors. It does not cover video downloading, stream ripping, DRM bypassing, private access workarounds, or copyright-restricted redistribution.

For quick browser-side testing, use the MetisTools M3U8 Player:

https://metistools.com/m3u8-player
